# TechFix Hub — IT Troubleshooting and Learning Hub

TechFix Hub is a static website that provides practical guides for solving common technology problems. It covers hardware, software, networking, and security topics, along with an interactive IT knowledge quiz.

## Features

- Troubleshooting guides for common IT problems
- Hardware, software, network, and security categories
- Searchable guide library
- Filters for keywords, categories, and difficulty
- Detailed guides with symptoms, possible causes, and solutions
- Safety notes for troubleshooting procedures
- Bookmark guides using browser storage
- Six-question IT knowledge quiz
- Saves the user's personal best quiz score
- Responsive page layout

## Pages

- `index.html` — Home page and featured guides
- `guides.html` — Searchable and filterable troubleshooting guides
- `guide-details.html` — Detailed troubleshooting instructions
- `bookmarks.html` — Saved troubleshooting guides
- `quiz.html` — IT knowledge quiz
- `about.html` — Information about the project

## Technologies Used

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Browse the troubleshooting guides or take the IT knowledge quiz.

For easier local testing, you can open the project using the Live Server extension in Visual Studio Code.

No database or PHP server is required.

## Data Storage

TechFix Hub uses browser storage to save bookmarked guides and the user's personal best quiz score. These saved items are stored locally in the browser and are not automatically shared across different browsers or devices.

## Project Purpose

TechFix Hub was developed to help students and other users learn basic IT troubleshooting through organized instructions and simple learning activities.
